# Sidecar v1.5.0 — a new look

Sidecar has a new identity and a redesigned app. It also includes the automatic model catalog from v1.4.5: models now come straight from the bundled Codex CLI, so new ones show up without waiting for a Sidecar update.

## New identity

- A new logo, **Split Pane**: a main pane with a narrow pane docked beside it. Your editor and its sidecar.
- New app icons on macOS and Windows, and a refreshed brand kit.
- Geist and Geist Mono throughout, bundled with the app so it works offline.

## Redesigned app

- **Home** answers "is it working?" at a glance, with a status orb and one clear next step, whether that's creating a key, signing in, or running a test.
- **Keys** show their setup progress (created → signed in → tested) right on each key, with an inspector beside the list.
- **Connect** puts VS Code, terminal, browser-app and endpoint snippets in one tabbed panel. Paste your secret once and every snippet fills in.
- Model picker shows each model's reasoning range and image support.
- **Activity** and **Health** replace Requests and Diagnostics, with live request counts in the sidebar.
- Command palette: press <kbd>⌘K</kbd> (or <kbd>Ctrl K</kbd>) to jump anywhere or run an action. <kbd>N</kbd> creates a key, and <kbd>G</kbd> then <kbd>H</kbd>/<kbd>K</kbd>/<kbd>C</kbd>/<kbd>A</kbd> jumps between pages.
- Pop-up confirmations for copies, tests, sign-ins and key changes.
- Motion throughout: page and card entrances, animated counters and sparklines, a sliding tab indicator, and a drawing check mark when a test passes. Everything respects your system's reduced-motion setting.
- A calmer first-run screen in the desktop app, and matching light and dark themes everywhere.

## Fixes

- Saved reasoning preferences and desktop connection defaults now keep `max` and `ultra` instead of silently dropping them.

## Also in this release (from v1.4.5)

- Models are read from the Codex CLI's own catalog at startup, after each sign-in, and every six hours. Retired models such as `gpt-5.4-mini` drop out automatically.
- Added `gpt-6.2-sol`, `gpt-6.2-astra`, `gpt-6.1-terra` and `gpt-6.1-sol`.
- Bundled Codex CLI updated to 0.172.0.

## Automatic-update support files

You do not need to download `latest.json`, `.app.tar.gz`, `.sig`, `SHA256SUMS`, or provenance files manually. The app downloads and verifies its update automatically. Use the installer links above for manual installation.
