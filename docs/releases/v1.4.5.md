# Sidecar v1.4.5 — automatic model catalog

Sidecar now reads its model list from the Codex CLI instead of a hardcoded list, so new models appear without waiting for a Sidecar update. This release also adds GPT-6.2 Sol, GPT-6.2 Astra, GPT-6.1 Terra, and GPT-6.1 Sol, and removes models Codex no longer offers.

## What changed

- Models, reasoning levels, and image support now come from the Codex CLI's own catalog. Sidecar refreshes it at startup, after each Codex sign-in, and every six hours. A signed-in key's catalog is preferred because Codex keeps it up to date from your account.
- Models that Codex no longer lists, such as `gpt-5.4-mini`, are no longer offered.
- `CODEX_MODELS`, `CODEX_IMAGE_MODELS`, and `CODEX_MODEL_EFFORTS` still pin a fixed list when set. They are now commented out in `.env.example`, so copying it no longer turns discovery off.
- Added `gpt-6.2-sol`, `gpt-6.2-astra`, `gpt-6.1-terra`, and `gpt-6.1-sol` to the built-in fallback list.
- Enabled image input and `low` through `ultra` reasoning for all four models.
- Updated the bundled Codex CLI to 0.172.0, which includes all four models in its catalog.

## Automatic-update support files

You do not need to download `latest.json`, `.app.tar.gz`, `.sig`, `SHA256SUMS`, or provenance files manually. The app downloads and verifies its update automatically. Use the installer links above for manual installation.
